## 二、文章结构模板

### 模板A：「推理链」型（最常用，约60%文章）

适用于：观点输出、现象分析、生活感悟

```
【标题】4-8字，判断句/动宾结构/偏正结构

【开头：标题延续】★82%文章的核心特征★
标题+逗号+正文直接展开，不寒暄不铺垫
约50-80字

【现象/切入点】
一个具体的事、经历、观察
用「我觉得」「我发现」「我注意到」引出
约100-150字

【推理展开】（核心段落，可重复2-3轮）
「因为A，所以B。」
「而B又会导致C。」
「如果D，那么E。」
「就像是……」（类比，让抽象变具体）
每轮约100-200字

【转折/深入】
「不过……」或「其实……」或「但是……」
引出新的视角或纠正：「不是A，而是B」
约100-150字

【继续推理】
「也就是说……」
「换句话说……」
「比如说……」（举例支撑）
约100-200字

【收尾】
升华金句 / 开放留白 / 个人判断
约50-80字
```

**实战框架**（以主题「AI焦虑」为例）：
```
标题：《在 AI 缓冲期应该做些什么》
→ 正文开头：标题+逗号+引出「缓冲期」概念
→ 展开：因为AI能做X，所以人的Y能力就成了关键
→ 类比：就像是汽车出现后，威胁马车夫的不是汽车，而是会开车的人
→ 转折：不过，问题不在于AI能做什么，而在于你能问出什么
→ 推进：如果你能问对问题，那么AI就能给出有价值的答案
→ 收尾：一个能够主动担负起责任、愿意思考的人，在任何时代都会过得还不错
```

适用于：日常观察、个人体验、小事见大

约80-120字

约100-150字

### 模板C：「问题解答」型（约15%文章）

适用于：回应读者、解释观点、技术/方法分享

```
【标题】事件型或动宾结构，4-8字

【开头：抛出问题】
标题+逗号+直接说明问题背景
或：「有人问我……」「经常有人觉得……」
约50-80字

【正面回应】
直接给判断，不绕弯子
「我觉得……」「我认为……」
约80-100字

【展开解释】（例子+推理交替）
「比如说……」→「因为A所以B」
「就像是……」→「也就是说……」
约200-400字

【补充/深化】
「当然……」（让步后加强）
「不过……」（补充限定条件）
约100-150字

【收尾】
「说到底……」或个人判断式收尾
约30-50字
```

## 三、开头公式（按实际频率排序）

### 公式1：标题延续式（82%，★默认使用★）
> 标题和正文是一个连贯句子，用逗号/句号衔接

- 《不太聪明的人》，凡事总是慢一拍……
- 《卖菜八年》，我就已经在网上卖菜满八年。
- 《群里是非多》，在网上贴各种群聊天截图，我就觉得很烦……
- 《寒气》。不是长马是短马，漂亮的皮革闪着光……
- 《爽文一时爽》，甚至是个大麻烦。

### 公式2：引用/对话切入（6.8%）
> 以引号、书名号或对话开始

- 《是法平等，无有高下》nana 说我每天文章的 AI 配图「有一股子塑料味」。
- 《翻译练习》·麦基老师在中国编剧界有着举足轻重的地位……

### 公式3：直入主题（6.8%）
> 不用任何连接词，直接开始叙述

- 《为什么我不用 AI 写文章》AI 已经那么强悍了，为什么我还在坚持手工敲字……
- 《最了不起的个人能力》「个人能力」这个词我听了小三十年……

### 公式4：问句切入（3.7%）
> 用问题开门见山

- 面对X，人们为什么不Y？
- 你有没有想过……？

## 四、核心句式工具箱

### 【推理系】—— 和菜头的思维骨架（使用最多）

| 句式 | 频率 | 用法 | 示例 |
|------|------|------|------|
| 因为A，所以B | 每篇0.73 | 因果推导 | 因为它是在清点拥有，所以容易焦虑 |
| 如果A，那么B | 每篇0.68 | 假设推理 | 如果你写不清楚，你就想不清楚 |
| A会导致B，B又会… | 常用 | 链式推理 | 感觉会左右心态，心态会影响判断 |
| 说到底… | 每篇0.03 | 揭示本质 | 说到底，都是用适合自己的方式去放松 |

### 【类比系】—— 和菜头的修辞利器（★最强标签★）

| 句式 | 频率 | 用法 | 示例 |
|------|------|------|------|
| 就像是… | 每篇0.78 | 生动比喻 | 就像是第一次去对象家，发现内裤穿反了 |

| 好比/好像 | 每篇0.16 | 口语化类比 | 好比你明知道路是歪的还要往前走 |

| 等于是 | 每篇0.05 | 直白等价 | 等于是把自己的底牌亮给了对方 |

### 【转折系】—— 扭转读者认知

| 句式 | 频率 | 用法 | 示例 |

| 句式 | 频率 | 用法 | 示例 |
|------|------|------|------|

### 【立场系】—— 建立个人视角

| 句式 | 频率 | 用法 | 示例 |
|------|------|------|------|

## 五、结尾公式

### 类型1：升华金句型（最有力）
> 把具体话题提升到人生/生活层面

- 「习惯向内而不是向外看，这是成为情绪稳定心态平和的成年人的必经之路。」
- 「你不安排你的生活，就有人会安排你，这可能是一个定律来的。」

**公式**：`习惯/学会 + 具体行为 + 这是/才是 + 更大意义`

### 类型2：个人判断型（最常用）
> 用「我觉得」「我认为」收束，有立场但不强迫

- 「这个世界真美好，每个人都有合适的事情可以去做。」
- 「一个能够主动担负起责任、愿意思考的人，在我看来无论在任何时代都会过得还不错。」

### 类型3：开放留白型（有韵味）
> 不给答案，留给读者

- 「大概是这样吧。」
- 「谁又知道呢？」
- 「也许是这样，也许不是。」

### 类型4：戏谑自嘲型（偶尔使用）
> 用幽默化解严肃，但不要每篇都用

- 「这个功能我看可以起个名字，就叫做「慈悲」好了。」
- 「当然，我说的可能都是错的。」

### 类型5：呼应开头型（结构感强）
> 首尾呼应，形成闭环

## 六、语言风格量化指南

### 6.1 人称使用（3:1:0.2）
- **「我」**：每篇约30次。大量使用，建立强烈的个人视角
- **「你」**：每篇约12次。制造对话感，但不要超过「我」的一半
- **「我们」**：每篇仅2次。极克制，用多了立刻变说教
- **第三方**：「他们」每篇3.5次，「大家」每篇1次，「很多人」用来引出现象

### 6.2 句式节奏
- **均句长44字**，比一般人预期的要长
- **长句主导**：31-50字的句子占31.7%，超过50字的占25.8%
- **短句点睛**：15字以下的短句占11.6%，用来收束和强调
- **节奏规律**：2-3个长句铺陈/推理 → 1个短句收束 → 继续

### 6.3 问句控制
- 每篇约6.4个问句
- 约每400字一个问句
- 作用：推进论述（设问→自答）、保持注意力、制造对话感
- 不要在一个段落里连问多个问题

### 6.4 语气词规范
| 语气词 | 频率 | 用法 |
|--------|------|------|
| 呢 | 每篇1.0 | 最高频，「怎么办呢？」「不是吗呢？」 |
| 吧 | 每篇0.6 | 推测/建议，「大概是这样吧」 |
| 吗 | 每篇0.6 | 反问/设问 |
| 啊 | 每篇0.4 | 偶尔使用 |
| 哈 | 每篇0.3 | 轻松调侃 |
| 嘛 | <0.1 | ★极少用★ |
| 呀 | <0.1 | ★极少用★ |

### 6.5 标点符号
- **直角引号「」**：每篇1.9次。标记概念、术语、特殊用法。★强个人标记★
- **破折号 ---**：每篇1.7次。解释补充、话题转换
- **书名号《》**：每篇5.5次。大量引用书、电影、文章
- **省略号**：每篇仅0.3次，很少用
- **不要用弯引号""**，一律改直角引号「」

### 6.6 情感基调分配
```
冷静理性 ████████████████████ 40%（理解/思考/观察/分析）
正面温和 █████████████████ 35%（喜欢/美好/快乐/温暖）
洞察点睛 ████████ 15%（本质/真正/核心/关键）
幽默自嘲 ███ 7%（有意思/好笑/尴尬）
批判质疑 █ 3%（荒谬/扯淡/愚蠢）
```

## 十、写作检查清单

### 结构检查
- [ ] 标题4-8字？无问号感叹号？
- [ ] 开头标题延续式（标题+逗号+正文）？
- [ ] 有完整的推理链条（因为/所以/如果/那么）？
- [ ] 有至少1次转折（不过/其实/但是）？
- [ ] 有至少1次认知纠正（不是A而是B）？
- [ ] 结尾有力（升华/留白/判断）？

### 语言检查
- [ ] 「就像是」类比至少2处？
- [ ] 「我」为主，「你」为辅，「我们」≤2次？
- [ ] 约每400字1个问句？
- [ ] 长短句交替（长句铺陈，短句收束）？
- [ ] 用了直角引号「」？用了破折号---？
- [ ] 语气词以「呢」「吧」「吗」为主？

### 基调检查
- [ ] 冷静理性为主基调？不是段子风？
- [ ] 金句不超过2句？不堆砌？
- [ ] 没有说教感？没有空洞套话？
- [ ] 没有喊口号、没有煽情？
