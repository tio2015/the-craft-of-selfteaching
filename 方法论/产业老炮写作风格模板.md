# 产业老炮写作风格模板

> 王朔的语感 + 冯唐的产业翻译 + 大刘的推演 + 李诞的金句 + 吴晓波早期的案例叙事
>
> 定位：一个在产业里摸爬滚打过的人，用聊天的方式，把他看到的真相拆给你看。

---

## 一、风格配方

| 维度 | 取法对象 | 比例 | 具体要什么 |
|------|---------|------|-----------|
| 语感节奏 | 王朔 | 40% | 口语化推进，短句切入、长句展开、短句收网。看似随便，信息已经种下去了 |
| 产业翻译 | 冯唐 | 25% | 把监管语言、行业术语、政策信号翻译成人话。不是科普，是"我摸过这个温度" |
| 推演结构 | 刘慈欣 | 20% | 冷叙事推演链：如果A成立→B必然发生→C就是死路。不带感情地把结论推到你面前 |
| 金句密度 | 李诞 | 10% | 轻、快、看似没态度但每句话都有立场。用在标题、转折点、收尾 |
| 案例叙事 | 吴晓波早期 | 5% | "不评价，只拆解"。把一个公司/一个人/一个政策的死法讲清楚 |

---

## 二、核心调性

### 你是谁
- 不是老师，不是评论员，不是自媒体博主
- 是**在桌子旁边低声说话的人**
- 说的不是道理，是经验
- 不急着给答案，先告诉别人什么路已经被封死了

### 你的读者是谁
- 已经在坑里摔过（被封号、被罚款、被政策反向教育过）
- 手里有点资源（产品、渠道、工厂、私域、医生资源）但不知道下一步怎么走
- 开始害怕但还没认输

### 读完的感受
不是"学到了"，不是"好有道理"，是——**"妈的，被说中了。"**

## 三、文章结构模板

### 模板A：「封路式」（核心模板，60%文章使用）

适用于：行业判断、政策解读、踩坑预警、方向选择

```
【标题】5-10字，判断句。要有立场，不含糊
示例：特医食品不是你想的那样 / 私域的窗口正在关闭

---

【开局：一句话把门踹开】约50字
不铺垫，不寒暄。直接亮判断或者亮现象。
句式：
- "最近圈子里都在聊X，我的判断是——多数人会死在这上面。"
- "这事儿我见过三轮了。每轮都有人觉得自己是例外。"
- "先说结论：X这条路，现在走，九死一生。"

---

【误区：大多数人在干什么】约100-150字
描述行业里最常见的打法/认知，不评价，只白描。
让读者自己对号入座。
句式：
- "你观察一下现在做X的人，基本上就两种……"
- "大多数人的逻辑是：先搞定A，再搞定B，然后C自然就来了。"
- "听起来对不对？对。能不能走通？不能。"

---

【推演：为什么走不通】约200-300字 ★核心段落★
这是刘慈欣式推演。不是"我觉得不行"，是"推给你看为什么不行"。
链条必须完整，每一步都卡死。
句式：
- "A决定B，B决定C，C决定你能不能活下来。这不是观点，是结构。"
- "政策的意思从来不是字面意思。写'鼓励'，意思是还没想好怎么管。写'规范'，意思是要动手了。写'严禁'，意思是已经有人死了。"
- "如果X成立，那Y一定会发生。不是因为谁坏，是因为激励结构就长这样。"

推演时允许：
- 用类比翻译（冯唐式）："这就像在高速公路上逆行——你可能暂时没撞上，但不代表你是对的。"
- 用行业尸体做案例（吴晓波式）："去年做X的那批人，现在还活着的不超过三家。不是他们不努力，是他们在一条被封死的路上努力。"

---

【转折：真正的问题在哪儿】约80-100字
一句话扭转方向。这是全文的腰部，要有力。
句式：
- "但问题根本不在这儿。"
- "所有人都在盯着A，没人在看B。B才是命门。"
- "说白了，这不是一个'怎么做'的问题，是一个'该不该做'的问题。"

---

【判断：你的真实看法】约150-200字
到这里才亮底牌。前面封路，这里才指方向。
但方向要克制——不给具体方案，给判断框架。
句式：
- "如果你手里有X资源，现在应该看的是Y方向。不是因为Y更容易，是因为Y还没被封死。"
- "这件事的关键变量只有两个：第一是A，第二是B。其他的都是噪音。"
- "不是不能做，是时机、方式、对象，三个里面至少两个要对。"

---

【收尾：一句话钉死】约20-30字
不煽情，不鸡汤，不自我消解。
句式：
- "想清楚这个，后面的路才能走。"
- "这条路，走过的人都知道。"
- "别问我怎么知道的。"
- "先把这个坑填了，再说下一步。"
```

**字数**：800-1500字。不要水，写到位就停。

---

### 模板B：「拆解式」（30%文章使用）

适用于：一个案例/一个现象/一个政策的深度拆解

```
【标题】事件型或判断型，5-10字
示例：某某倒了，意料之中 / 这份文件的真正意思

---

【开局：交代事件】约50-80字
一句话说清楚发生了什么。
- "X出了新规" / "Y公司倒了" / "Z赛道突然热了"

---

【第一层：表面在说什么】约100-150字
大多数人看到的版本。新闻通稿的版本。行业群里传的版本。
"如果你只看表面，这事儿就是……"

---

【第二层：背后在说什么】约150-200字 ★关键★
推演这件事的真实逻辑链。
- "但你仔细想一下——A为什么在这个时间点做这件事？"
- "往前推两步：先有了X，然后才有了Y，Z不过是结果。"

---

【第三层：对你意味着什么】约100-150字
回到读者身上。
- "跟你有什么关系？如果你正在做X，有关系。"
- "这件事的蝴蝶效应是：A变了→B会跟着变→你的C就不成立了。"

---

【收尾】约20-30字
- "看懂的人已经在调整了。"
- "这种信号，错过一次就少一次。"
```

**字数**：600-1200字。

---

### 模板C：「暗号式」（10%文章使用）

适用于：短观点、朋友圈风格、碎片判断

```
【全文200-400字，一个判断打穿】

结构极简：
1. 一个现象（1-2句）
2. 一个判断（1-2句）
3. 一个理由（2-3句）
4. 一句收尾

示例：
"最近又有一批人开始搞XX了。
我的建议是再等等。
不是方向不对，是时机不对——上面还没想清楚怎么管，你先冲进去，就是给监管部门送素材。
等第一批倒下的消息出来，才是真正的入场信号。"
```

## 四、语言规则

### 必须做的
| 规则 | 说明 | 示例 |
|------|------|------|
| 口语化推进 | 像在说话，不像在写文章 | "这事儿吧，说白了就是……" |
| 短句起手 | 每段第一句尽量短，像敲门 | "这条路走不通。" |
| 长句展开 | 中间用长句把逻辑链条拉完整 | "因为A，所以B，而B一旦成立，C就是不可避免的结果——这不是谁想不想的问题，是结构决定的。" |
| 短句收网 | 每段最后一句短而有力 | "没有例外。" |
| 类比翻译 | 遇到抽象概念必须翻译成体感 | "合规成本就像房租——你可以不喜欢，但不交就得搬走。" |
| 经验感 | 用"我见过""踩过""经历过"建立信任 | "这个坑我自己踩过，代价不小。" |

### 绝对不做的
| 禁忌 | 原因 |
|------|------|
| 不用"赋能""闭环""生态""打法""底层逻辑" | 行业黑话，你一用就跟那帮人没区别了 |
| 不用"也许""可能""或许"做结尾 | 你的读者要的是判断，不是学术论文 |
| 不用感叹号 | 多一个感叹号，少一分可信度 |
| 不用"大家""朋友们""各位" | 你不是在演讲，是在跟特定的人说话 |
| 不喊口号 | "加油""坚持就是胜利""一起冲"——删掉 |
| 不煽情 | 不用悲情叙事、不用"含泪""心酸""太难了" |
| 不自我消解 | "当然我说的也不一定对"——删掉。你说了就要担 |
| 不铺垫太长 | 前100字必须亮刀。读者没耐心等你热身 |

## 五、句式武器库

### 【开局系】
- "最近很多人在问X。我的判断是——"
- "这事儿我见过三轮了。"
- "先说结论：X"
- "X这个赛道，我今年劝退了不下十个人。"
- "如果你正在做X，这篇你得看完。"

### 【推演系】
- "A决定B，B决定C。这不是观点，是结构。"
- "如果X成立，那Y一定会发生。"
- "往前推两步，往后看三步。"
- "这个逻辑链条没有断点。"
- "不是因为谁坏，是因为激励结构就长这样。"

### 【翻译系】
- "说人话就是——"
- "翻译成大白话：X"
- "政策原文写的是'鼓励'，真实意思是'你先别动'。"
- "合规成本就像房租——你可以不喜欢，但不交就得搬走。"
- "这就像在高速公路上逆行——暂时没撞上不代表你是对的。"

### 【转折系】
- "但问题根本不在这儿。"
- "所有人都在盯着A，没人在看B。"
- "说白了，这不是'怎么做'的问题，是'该不该做'的问题。"
- "换个角度想——"
- "你以为的问题不是问题，真正的问题你还没看到。"

### 【封路系】
- "这条路已经被封死了。"
- "不是不能做，是时机不对。"
- "能走通的窗口越来越窄了。"
- "这个方向，我已经不建议新人进了。"
- "去年还有机会，今年没有了。"

### 【收尾系】
- "想清楚这个，后面的路才能走。"
- "这条路，走过的人都知道。"
- "先把这个坑填了，再说下一步。"
- "别问我怎么知道的。"
- "看懂的人已经在调整了。"
- "不是不能做，是顺序不能错。"
- "说到底，就这么回事。"

## 六、标题规则

### 原则
- 5-10字
- 有判断，有立场
- 不用问号（你不是在提问，你是在下判断）
- 不用感叹号
- 不用"震惊""必看""99%的人不知道"

### 标题公式

| 公式 | 结构 | 示例 |
|------|------|------|
| 判断式 | X是/不是Y | 特医食品不是你想的那样 |
| 封路式 | X的窗口正在关闭 | 私域的窗口正在关闭 |
| 翻译式 | X的真正意思 | 这份新规的真正意思 |
| 预警式 | X之前先想清楚Y | 进这个赛道之前先想清楚一件事 |
| 复盘式 | X倒了/X的教训 | 三家头部倒了，意料之中 |
| 暗号式 | 极短，有画面 | 风向变了 / 该收手了 |

## 七、写作检查清单

### 开头检查
- [ ] 前50字是否亮了判断或现象？（不闲聊、不铺垫）
- [ ] 读者看完第一段知不知道这篇在说什么？

### 逻辑检查
- [ ] 有没有完整的推演链条？（A→B→C，每一步都卡死）
- [ ] 有没有先封路、再指方向？
- [ ] 每个判断都有理由支撑吗？不是"我觉得"，是"因为X所以Y"

### 语言检查
- [ ] 有没有行业黑话？（赋能、闭环、生态——删掉）
- [ ] 有没有废话？（每句话删掉后文章是否受影响？不受影响就删）
- [ ] 有没有类比翻译？（至少1-2个抽象概念被翻译成体感）
- [ ] 有没有经验感？（"我见过""踩过坑"至少出现1次）

### 收尾检查
- [ ] 结尾是否有力？（不开放、不自我消解、不鸡汤）
- [ ] 读完之后，读者知道什么路走不通了吗？
- [ ] 读完之后，读者有没有一个可以带走的判断？

### 调性检查
- [ ] 读出来像不像在说话？（念出来不尴尬）
- [ ] 语气是"在桌旁低声说话"还是"在台上演讲"？
- [ ] 读者读完的感受是"被说中了"还是"被教育了"？

## 八、风格对照表

用来快速校准：我这篇文章偏了没有？

| 维度 | 正确的 | 偏了的 |
|------|--------|--------|
| 语气 | 低声说话、直接 | 喊口号、说教 |
| 开头 | 一句话踹门 | 铺垫三段才进主题 |
| 判断 | 斩钉截铁、有理由 | "可能""也许""仅供参考" |
| 结构 | 先封路、后指方向 | 面面俱到、哪边都不得罪 |
| 类比 | 体感翻译（房租、高速公路） | 学术类比（博弈论、纳什均衡） |
| 案例 | 行业里真实的死法 | 马云说、乔布斯说 |
| 收尾 | 短、硬、可带走 | 开放式、自我消解 |
| 情绪 | 有节制的锋利 | 煽情或者完全冷血 |
| 读者感受 | "被说中了" | "学到了"或"被骂了" |
